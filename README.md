# ai-engineering
Exemplary ai systems project

## Setup
1. Install dependencies:
   ```bash
   uv sync
   ```
2. Configure environment variables in a `.env` file:
   ```env
   PINECONE_API_KEY=your_pinecone_api_key
   PDF_DIRECTORY=attachments
   ```

## Usage
Run the main script:
```bash
uv run main.py
```
